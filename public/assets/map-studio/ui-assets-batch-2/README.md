# Map Studio UI Assets Batch 2

This batch covers UI elements not included in the first button asset package.

Folders:
- icons/status: top status bar icons.
- icons/nav: top-right navigation icons.
- icons/schedule: bottom itinerary/action bar icons.
- styles: readability CSS for Map Studio labels.

Primary fix:
- Increase top button/status label contrast.
- Keep Chinese labels readable against dark metal/paper buttons.

Suggested use:
- Keep text rendered by code.
- Use these SVGs for icons only.
- Apply styles/map-studio-readable-buttons.css or port its tokens into existing CSS modules.

# Map Studio Marker Assets

Small SVG marker set for Wanderly Map Studio.

Files:
- marker-attraction.svg: scenic spots / landmarks.
- marker-food.svg: food and restaurants.
- marker-hotel.svg: hotels and accommodation.
- marker-transport.svg: stations, airports, transport nodes.
- marker-favorite.svg: user saved places.
- marker-candidate.svg: added to candidate list.
- marker-planned.svg: already written into itinerary.
- marker-unresolved.svg: place exists but coordinate/category is unresolved.

Suggested display rules:
- Low zoom: hide place markers, show region labels only.
- Mid zoom: show high-priority markers without text labels.
- High zoom: show more markers.
- Hover: show place name tooltip.
- Selected: show full place label and details panel.

Do not display every label permanently.

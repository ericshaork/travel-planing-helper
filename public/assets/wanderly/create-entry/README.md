# Wanderly Create Entry Assets

用于「开始一次旅行」页面的小素材包，不包含 logo。

## icons/

- `import-plan.svg`：导入已有计划
- `ai-guide.svg`：AI 创建
- `blank-plan.svg`：直接新建计划

## decor/

- `compass-line.svg`：轻量罗盘线稿
- `route-dots.svg`：虚线路线装饰
- `archive-stamp.svg`：Wanderly 档案邮戳
- `luggage-tag.svg`：行李牌线稿
- `ticket-corners.svg`：票据角标装饰

建议先用这些素材支撑页面结构，装饰透明度控制在 `0.15-0.45`，不要让线稿抢过三张创建入口卡。

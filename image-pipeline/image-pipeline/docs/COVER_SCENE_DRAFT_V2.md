# Cover Scene Draft V2

This draft replaces V1 for manual review only.

Goal:
- design five clearly differentiated Explore cover scenes per city
- treat each scene as a magazine-cover visual story, not a destination slogan
- reduce repeated city cliches that would collapse into similar generated images

Design rules:
- each city covers five fixed visual categories:
  - Icon Landmark
  - Local Life
  - Architecture / Street
  - Food / Craft
  - Nature Escape
- the same core visual symbol should not dominate multiple scenes
- each scene should remain recognizable at thumbnail size
- every scene should feel like Wanderly: light watercolor, private travel journal, quiet editorial tone

## Recommended Review Focus

- Check same-city scenes at thumbnail size first, not full-screen first.
- Ask whether each city's five scenes really look like five different magazine chapter covers.
- Watch for repeated hero objects that could collapse output diversity:
  - Hangzhou: pavilion / boat / lotus / lake plane
  - Chengdu: tea table / bamboo chair / teahouse frontage
  - Yunnan: broad mountain panorama / generic village cluster
- Check whether `food_craft` scenes are tactile enough to be illustrated, not just listed as cuisine categories.
- Check whether `local_life` scenes still feel aspirational and beautiful enough for an Explore cover.
